# データの取得元と利用条件

現在は FujitsuResearch が公開した [Fujitsu RAG Hard Benchmark](https://github.com/FujitsuResearch/Fujitsu-RAG-Hard-Benchmark) を使用します。

- 固定コミット: `39fc62415ae5557f51d61ae64faf05494703afe5`
- `fujitsu.json`: このコミットから直接取得する 5 文書の URL と SHA-256。
- `title`: 正解データの `rationales.file_name` と照合できるよう、元のファイル名を保持。
- 原文 PDF と正解データ: Git 管理対象外の `data/` に保存。
- 正解データ: 100 問の回答、証拠ファイル名、1 始まりのページ番号、難度などを含む YAML。`uv run jp-doc-agent fetch-benchmark` で改変せずに取得。

## 現在の部分集合

5 文書・170 ページは、以下の 16 問の全証拠文書をカバーします。

`64, 65, 66, 67, 68, 69, 70, 71, 73, 74, 75, 76, 77, 78, 80, 81`

これは証拠文書のカバー範囲に基づく選定で、全問が本文だけで回答可能という意味ではありません。図表を読む必要のある問題もあるため、本文・表・視覚情報を必要とするタスクを分けて評価する予定です。未取得の証拠文書を参照する問題は、この部分集合の正解率に含めません。

正解と証拠ラベルは評価にのみ使用し、本文・チャンクのテーブルや回答生成のプロンプトには登録しません。

## 利用範囲

上流の [利用規約](https://github.com/FujitsuResearch/Fujitsu-RAG-Hard-Benchmark/blob/39fc62415ae5557f51d61ae64faf05494703afe5/TERMS_OF_USE.md) では、ソフトウェアと PDF の条件を区別しています。ソフトウェアは Apache-2.0 ですが、提供 PDF は本ベンチマークの評価用途に限定され、商用利用や再配布などは禁止されています。

本プロジェクトでは PDF をローカルの評価開発に利用します。公開リポジトリには自身のコード、取得元一覧、説明のみを含め、PDF や抽出本文・チャンクは掲載しません。PDF を使った公開文書サービスも提供しません。公開デモや商用利用では、別途利用を許可された資料を用意する必要があります。
